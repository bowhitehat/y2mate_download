Thiết lập Google lần đầu Cần file OAuth JSON

Chỉ cần thiết lập một lần cho bản chạy trên máy. Y2Music xin quyền chỉ đọc YouTube; bạn đăng nhập và cấp quyền trên trang Google.

  1. Bật API. Tạo hoặc chọn một dự án trong Google Cloud → YouTube Data API v3, rồi chọn Enable.
  2. Thiết lập ứng dụng. Vào Google Auth Platform. Điền tên ứng dụng và email hỗ trợ trong Branding. Ở Audience, chọn External, giữ chế độ Testing và thêm email Google của bạn vào Test users. Trong Data Access, thêm quyền https://www.googleapis.com/auth/youtube.readonly.
  3. Tạo OAuth Client. Vào Clients → Create client → Desktop app, đặt tên Y2Music và tải file JSON về máy. API key và file loại Web application không dùng cho bước này.
  4. Chọn file bên dưới, sau đó bấm Kết nối Google. Nếu có nhiều kênh, chọn đúng kênh chứa playlist của bạn.

File cấu hình và phiên kết nối lưu trong thư mục data/ trên máy, được bỏ qua khi đẩy GitHub. Trên Windows, thông tin kết nối được mã hóa theo tài khoản Windows của bạn.

Nếu Google báo access_denied, kiểm tra đúng email trong Test users. Nếu chưa lấy được playlist, kiểm tra API đã bật và đúng kênh YouTube. Ứng dụng đang Testing có thể yêu cầu kết nối lại sau khi phiên hết hạn.
